In-house Technologies & Engineering

Custom engines, frameworks and toolkits

Beyond end-user applications and games, I build dedicated engines, frameworks and engineering tools to solve specialized challenges in physics, 3D rendering, networking and game architecture.

V-Engine

3D World & Spatial Physics Engine (v0.14.0)
In-house Engine

Real-time Flutter engine with GPU rendering on Web and desktop, alternative 3D backends and a pure Dart spatial core. It includes animated glTF models and an independent 2.5D stage with atmosphere and post-processing effects.

  • WebGL2 / Flutter GPU
  • Skeletal glTF Models
  • Raycasting & Portals
  • Dynamic Shader Lighting
  • Dart Spatial Physics
  • 2.5D Stage, Atmosphere & Transitions
Used in: Drezkul, R3Forma, Game Editor

PlayForge

Modular Game Toolkit & Plugin (v0.39.0)
In-house Toolkit

A modular toolkit and native plugin for Flutter and Flame, shared by the games and the visual 2.5D platform. It brings together input, audio, saves and networking, plus the project format, editing, game logic and narrative libraries in pure Dart.

  • Gamepad & Touch Controls
  • Low-Latency Web Audio
  • Multiplayer & Client Prediction
  • Saves & Schema Migrations
  • 2.5D Project Format
  • Project Editing, Logic & Narrative
Used in: Salad Survivors, Deep Space Fishing, Drezkul, Game Editor
