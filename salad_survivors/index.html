⚠️ Servidor Web Necessário

O Flutter Web utiliza módulos JavaScript, WebAssembly e CanvasKit, que são bloqueados pelos navegadores quando abertos diretamente com dois cliques no arquivo (file://).

Para executar o jogo no navegador, execute o servidor local com o arquivo iniciar_web.bat na pasta do jogo ou execute no terminal:

python -m http.server 8080 --directory build/web

Em seguida, acesse no navegador: http://localhost:8080
