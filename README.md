# Portfólio de André Luiz Nogueira

Site estático para GitHub Pages, em HTML e CSS, sem dependências de build.
A página inicial reúne Listagem, Hora do Pet e Salad Survivors. As imagens
em `assets/` foram copiadas dos projetos originais.

## Políticas individuais

- Listagem: https://andreluiznogueira.github.io/licencas/listagem/
- Hora do Pet: https://andreluiznogueira.github.io/licencas/hora-do-pet/
- Salad Survivors: https://andreluiznogueira.github.io/licencas/salad-survivors/

Depois da publicação, atualizar os links nas lojas e nos aplicativos que
ainda apontem para a raiz. A raiz agora é o portfólio. A política conjunta
anterior está em `/licencas/anteriores/`; `/en.html` continua acessível e
indica onde encontrar as políticas individuais atuais, em português.

O jogo web existente continua em `/salad_survivors/`. O arquivo `app-ads.txt`
continua na raiz para os serviços de anúncios.

## Manutenção

Edite `index.html` para descrições e links; `style.css` contém o estilo
compartilhado com as novas políticas. Cada política é uma página HTML
independente, em `licencas/<projeto>/index.html`.

As políticas foram preparadas a partir da política anterior e dos projetos
locais em 18/09/2026. A do jogo contempla placar opcional, fila de pontuações,
código do jogador e exclusão nas versões compatíveis, relatórios manuais,
armazenamento local e compras no Google Play. Não pressupõe que migrações
locais já estejam aplicadas no servidor. O projeto não documentava prazo
automático de exclusão dos registros online; o texto explicita isso. Se uma
rotina de retenção for definida, atualize a política junto com o serviço.

Fontes dos serviços: [dados do AdMob](https://developers.google.com/admob/android/privacy/play-data-disclosure),
[Google](https://policies.google.com/privacy) e [Supabase](https://supabase.com/privacy).
